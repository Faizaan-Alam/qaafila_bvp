## What is Qaafila?

Qaafila is a fun literary society, and a **pariwaar**.

Poetry, shayari, acting, standup, open mic, a podcast, dance, rap, a book club, and the bonds that hold it together. It was founded in May 2022 at BVP by Keshav Goyal and Mayank Hora.

This site is the house for that: the team, the people who came before, selected members, evenings, write-ups, and memories.

Official Instagram: [@qaafila_bvp](https://www.instagram.com/qaafila_bvp)

This repository is owned by the official Qaafila GitHub, [qaafilabvp](https://github.com/qaafilabvp/qaafila_bvp). I made the site.

## Run it locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build
npm run preview
```

Stack: React, Vite, Tailwind, JavaScript.

Portraits go in `src/assets/images/members/` and get wired in `src/data/members.js`.  
Selected members live in `src/data/selectedMembers.js`.  
Legacy tenures live in `src/data/legacy.js`.
